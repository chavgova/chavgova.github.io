# Legacy WordPress content import — for the new portfolio

This bundle is a curated, user-provided content import extracted from three saved WordPress/Wayback HTML pages and companion ZIP files. It is **NOT a website template** and does not include WordPress code, old JS/CSS, or the old logo.

## Usage
1. Extract this ZIP into the root of the local GitHub Pages repository, maintaining its paths.
2. Give Codex the separate implementation prompt provided in the ChatGPT response.
3. Codex should read `migration/legacy-site/ARCHIVE_CONTENT_GUIDE.md` and the reference texts in `migration/legacy-site/archive-text/` before writing project copy, and use the 12 hand-selected images in `src/assets/legacy/` wherever appropriate.
4. After content migration, Codex can remove the `migration/legacy-site/archive-text/` temporary reference files or exclude them from site deployment, but should keep `ARCHIVE_CONTENT_GUIDE.md` and asset provenance information somewhere accessible for future editorial reference.
5. Provide a **new professional portrait** (transparent PNG/WebP) and a **current CV** separately. Neither is in the bundle.

All imported content is historical; it must be edited for a modern, industry-focused portfolio. It is never acceptable to invent dates, credentials, metrics, role titles, or links. Check accuracy and confidentiality before publishing.
