## Context & problem

Electron microscopy connects scientific instrumentation with application software. Machine learning can support these workflows, while software engineering provides the interface between experimental methods and their use within an instrument-oriented environment.

## My contribution

As a part-time Application Software / AI Engineer, I built an RTMDet vision pipeline for SEM imagery and integrated model inference into Phenom microscope workflows. My contribution also included configurable, multithreaded application workflows that translated domain requirements into maintainable software components.

## Technical method

The work connected model experimentation, training, evaluation, and inference integration with scientific application software. Valohai MLOps supported the ML workflow, while targeted experimentation and hyperparameter tuning addressed detection behavior. The application work focused on configurable automation for Phenom SEM systems.

## Results & lessons

The CV records production integration of the vision pipeline and delivery of multithreaded application workflows. This experience brought model development together with the engineering requirements of scientific instruments and existing software workflows.
